# ExportWhy — demo video script (target 3:55, hard max 4:00)

Record at 1920×1080, 30 fps. Screen capture of the UI (offline mode for responsiveness, one live
run pre-recorded), the Zetaris Data Explorer, a terminal, and one slide for the end. Voice-over in
English; captions on. No keys or tokens on screen: `.env` never appears; the Nightshift Console is
shown with the key blurred or not shown at all.

The video tells the whole story on its own (the judges may not have read the deck): the problem,
what the product delivers, the investigation running, how the sponsor technology takes part, what
the analyst does with the result, what happens when evidence is missing or a source is down, then the
numbers and limits.

Prepare before recording:
- `rm -rf memory && SAMPLE_MODE=true python -m agent.main alert AL-001` (so the World Model knows u1022)
- the UI shows each citation as a tag (`dexa.tickets.valid_to | q6`); the CLI report writes the same citation in brackets
- the recorded live runs in `docs/examples-live/` open in an editor: AL-004 (current rules, 231 s) and AL-011 (historical Critic demonstration, 298 s, recorded before the stricter SQL rules)
- UI running (`streamlit run ui/app.py`), mode "Offline sample"
- Zetaris Data Explorer open on the three datasources and the `dexa` container
- terminal at the repo root, ready to run `grep '"action": "model_call"' docs/examples-live/AL-011-nemotron-trace.jsonl`
